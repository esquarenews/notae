# Notae API v1

Base path: `/api/v1`

## Authentication

Use token authentication on every request:

- `Authorization: Bearer <api_token>`
- `Accept: application/json`
- `Content-Type: application/json` (for write operations)

Token model: `ApiToken`

- Token entropy: >= 32 bytes (`SecureRandom.urlsafe_base64(32)`)
- Revocation: set `revoked_at`
- Optional expiration: `expires_at`

## Rate limiting

Applied per token across all v1 endpoints.

- HTTP status: `429 Too Many Requests`
- Error payload:

```json
{
  "error": {
    "code": "rate_limited",
    "message": "Rate limit exceeded"
  }
}
```

Configuration:

- `API_RATE_LIMIT_PER_MINUTE` (default `120`)
- `API_RATE_LIMIT_WINDOW_SECONDS` (default `60`)

## Error schema

All API errors return:

```json
{
  "error": {
    "code": "string",
    "message": "string",
    "details": {}
  }
}
```

`details` is optional and typically present for validation failures.

## Authorization model

- Workspace access resolved through `policy_scope(Workspace)`.
- Every list endpoint uses `policy_scope(...)`.
- Record-level actions use Pundit `authorize`.
- Cross-workspace access returns `404` from scoped lookups.
